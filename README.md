# 🍙 냠냠 맛집지도

ChatGPT(OpenAI API)가 지역별 맛집을 추천해 주는 귀여운 웹앱이에요.

## 주요 기능
- 📍 지역 입력 (빠른 선택 버튼 제공)
- 🍽️ 카테고리 선택: 한식 · 중식 · 일식 · 양식 · 분식 · 고기 · 해산물 · 아시안 · 카페·디저트 (여러 개 선택 가능)
- 💰 가격대 / 👫 동행 / 🔢 추천 개수 옵션
- 맛집 카드를 누르면 **위치(지도) · 추천 메뉴 · 가격 · 방문 꿀팁** 표시
- 네이버지도 · 카카오맵 · 구글지도 바로가기

## 실행 방법
1. 배포된 주소(GitHub Pages)에 접속하거나 `index.html`을 브라우저로 엽니다.
2. 오른쪽 위 **🔑 API 키 설정**에 본인의 OpenAI API 키를 입력합니다.
3. 지역과 카테고리를 고르고 **맛집 찾기**를 누르면 끝!

## API 키 관련 안내
- API 키는 **코드에 들어 있지 않아요.** 사용하는 사람이 각자 화면에서 입력하고, 그 사람의 브라우저(localStorage)에만 저장됩니다.
- ⚠️ `index.html`에 API 키를 직접 적어서 GitHub에 올리지 마세요. 공개 저장소에 올린 키는 바로 유출돼요.
- OpenAI 키 발급: https://platform.openai.com/api-keys
